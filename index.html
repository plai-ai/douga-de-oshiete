動画で教えて。見るのはエンジニアではない社長で、この修正を本番に出してよいか決めたいです。

見る人と決めたいことが分からない場合、AIが最初に1問だけ聞きます。答えると、原稿・おすすめと理由・指示文・確認質問ができます。

できた原稿と指示文をNotebookLMへ貼り、動画解説を生成します。混雑などで時間は変わります。

# 動画で教えて（チャット版）— ChatGPT・Gemini・Claude に貼るだけ

Claude Code を使っていない方はこちら。下の枠の中を**まるごとコピー**して、ChatGPT・Gemini・Claude のどれかに貼り、`〈 〉` の所だけ書き換えて送ってください。
読めない資料は、この文のすぐ下に貼るか、ファイルとして添付します。

> ⚠ パスワード・APIキー・お客さんの名前は、貼る前に消してください。AIにも「消して」と指示していますが、最初から入れないのがいちばん安全です。

```text
あなたは、読みにくい資料を、見る人が10分の動画で理解して判断できる形に書き直す担当です。
これから渡す資料をもとに、Gemini Notebook（旧NotebookLM）の「動画解説」に入れる材料を3つ作ってください。

【この動画を見る人】〈例：エンジニアではない社長〉
【見たあと決めたいこと】〈例：この修正を本番に出してよいか〉

■守ること
・資料に書いてあることだけを使い、分からないことは「未確認」、推測は「（推測）」と書く
・パスワード、APIキー、トークン、個人名、メールアドレス、電話番号、社内URLは【伏せ字：種類】に置き換える
・中学生でも分かる言葉で、1文はなるべく60字以内。各章に身近なたとえを1つ入れる
・全体の3〜4割を「元の問題」と「原因」に使う

■作るもの1：説明の原稿（3,000〜8,000字・見出しはこの順番）
# 題名（何が起きて、何を決めるのか）
## この動画を見る人と、決めたいこと
## 30秒でいうと（結論を3文。決めたいことへの答えを先に）
## 1. 元の問題
## 2. 原因
## 3. やったこと（番号つきの手順）
## 4. その方法を選んだ理由（ほかの案2つ程度と比べて）
## 5. これからの運用（誰が・いつ・何を）
## 6. 注意点とリスク（セキュリティ・お金・元に戻せるか、を必ず）
## 7. 同じ失敗を防ぐ方法
## 8. おすすめ（AIの意見）：「私ならこうします」＋理由3つ＋判断が変わる条件
## 用語集（用語ごとに1〜2行・たとえ話で）

■作るもの2：動画解説の「重視するポイント」欄に貼る文（300字以内）
次の文の〈 〉を埋め、誤解されやすい点があれば「〜とは言わないでください」を最大3つ足す。
「日本語で、〈見る人〉が〈決めたいこと〉を判断できるように説明してください。原稿の本文を正しい情報として扱い、原稿にない推測は足さないでください。元の問題と原因から順に説明し、最後にAIのおすすめと、その判断が変わる条件を伝えてください。専門用語は、使うたびに短く言い換えてください。長さは7〜9分を目安にしてください。」

■作るもの3：承認前の確認質問を5つ
見る人が自分の言葉で答えられれば「分かった」と言える質問を5つ。決めたいことに直結するものだけ。各質問に、答えが書いてある原稿の章を付ける。

最後に、出す前に次を確かめてから出力してください：見る人と決めたいことが原稿と指示の文の両方に入っている／おすすめに意見・理由3つ・条件がある／伏せ字以外の秘密の値が残っていない。

▼資料
〈ここに資料を貼る〉
```

## できあがったら（Gemini Notebook で3分）

1. https://notebook.google.com を開き、「新しいノートブック」を押す
2. ソースの追加で「コピーしたテキスト」を選び、**作るもの1（原稿）**を貼って「挿入」
3. 右側の「動画解説」を押して「動画解説をカスタマイズ」を開き、形式＝説明動画／ビジュアル スタイル＝ホワイトボード（おすすめ）／言語＝日本語。「この動画で重視するポイントは何ですか？」→「カスタム トピック」に**作るもの2**を貼って「生成」
4. 10〜15分待つ（混んでいると30分以上かかることもあります）
5. 見終わったら、同じノートのチャットに**作るもの3（確認質問）**を貼り、自分の言葉で答えられるか確かめる

※仕事の資料を入れたノートでは、回答の評価ボタン（👍👎）は押さないでください。評価を送ると、そのやり取りを人が確認することがあります。
